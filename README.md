## Task Management App – Laravel + React

A Trello-style task management web application featuring list/card creation and drag-and-drop functionality.

## Features

- Built with [Laravel](https://laravel.com/).
- Interactive frontend built using [React](https://react.dev/).
- Drag-and-drop task reordering.
- Create, update, and delete boards, lists, and tasks.
- Using [Tailwind CSS](https://tailwindcss.com/).
